Settings

Keys are stored on your Flower server (SQLite) and are never sent back to the browser. Only the last 4 characters are shown.

AI model (bring your own key)

Used for the annual-report analysis and the "Ask about this stock" chat. DeepSeek is inexpensive; any OpenAI-compatible service works.

Model names change often. Check your provider's documentation for current model IDs if the test fails.

Web search for annual reports

US companies are read directly from SEC EDGAR (free, no key). For other companies (e.g. DAX members) Flower searches the web for the annual report PDF. Without a key it uses DuckDuckGo's HTML page, which works but can be rate-limited. Tavily and Brave Search offer free API tiers.

Server

Base currency, data mode, login and port are set in the .env file on the server (see README).
